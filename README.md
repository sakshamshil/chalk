# Chalk

A limitless workout tracker for Android. No log limits, no subscription, no account. All data stays on your phone.

## Install

1. Open the [latest release](https://github.com/sakshamshil/chalk/releases/latest) on your Android phone.
2. Download `chalk-vX.Y.Z.apk`.
3. Open the file. Android asks to allow installs from your browser or file app. Allow it, then tap **Install**.

Updates: Chalk tells you when a new version is available. Installing an update keeps your data.

## What it does

- Log workouts with weight, reps, time, distance and more. Warm-up, drop and failure sets, RPE, supersets.
- Previous values and a rest timer for every set. Live PR badges.
- Routines with folders. Import a plan from Claude (or any AI) as a JSON file.
- Import your history from Strong or Hevy (CSV).
- Records, estimated 1RM, charts, body weight trend.
- Backup to a file and restore.

This repository holds only the APK releases.
